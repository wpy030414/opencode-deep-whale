# PRD · 深海女仆工坊（Maid Atelier）

## 背景与动机

OpenCode Desktop 是面向开发者的 AI 编程助手桌面客户端。其默认界面以功能为导向，视觉风格偏工具化、缺乏个性。对于长时间使用的开发者而言，一个赏心悦目的界面能显著提升使用体验与情感连接。

"深海女仆工坊"项目的目标是：**将高质量的角色立绘与精心设计的色彩体系，以零侵入的方式注入 OpenCode Desktop**，让开发者在日常工作中享受到视觉上的愉悦，同时保持原生功能的完整性和性能。

## 目标用户

- OpenCode Desktop 的日常使用者
- 对界面美学有追求、喜欢个性化定制的开发者
- 喜欢二次元/角色立绘文化的用户群体

## 核心需求

### 1. 视觉主题覆盖

- **亮/暗双主题**：完整覆盖 OpenCode 的全部 CSS 变量（palette + v2Overrides），确保在任何主题模式下视觉一致性。
- **角色立绘**：主内容卡片和新会话界面底部左右两侧展示女仆角色立绘，高度分别为 78% / 72%，向内偏移 16px，不遮挡文本内容。
- **宫殿背景**：以 `::before` 伪元素叠加在主内容卡片和新会话界面上，opacity 0.12，营造氛围但不影响可读性。
- **透明层**：侧栏、主区域、提示输入栏（prompt dock）等区域做透明/半透明处理，让底层背景和角色透出。

### 2. 品牌替换

- **favicon**：替换 `favicon-v3.svg` 为女仆徽标（原创矢量）。
- **logo-mark**：侧栏品牌 SVG 内容替换为女仆风格的自定义 glyph。
- **默认项目头像**：拦截指向 `opencode.ai/favicon` 的 `<img>` 标签，重路由为内嵌的 maid icon data URI。

### 3. 一键安装与还原

- **自动备份**：首次补丁前自动备份原始 `app.asar` 为 `.maid-atelier.bak`。
- **强制重打**：`--force` 参数从备份恢复 pristine 版本再重新打补丁。
- **自动重启**：补丁完成后自动启动 OpenCode。
- **运行检测**：检测 OpenCode 是否在运行，自动终止进程（或 `--allow-running` 跳过）。

### 4. 安全与隔离

- **纯展示层**：所有注入仅限于 CSS 样式和 DOM 装饰，不修改任何业务逻辑、API 调用、事件系统。
- **CSS 作用域隔离**：全部选择器挂在 `html[data-maid-skin]` 下，卸载皮肤（移除属性）即可恢复原生样式。
- **零远程依赖**：所有素材以 base64 data URI 内嵌，无网络请求、无临时文件。
- **SPA 防丢失**：MutationObserver 监听 DOM 变化，React 重渲染后自动重新注入被清除的节点。

### 5. TUI 终端主题

- 为终端版 opencode 提供配套的 JSON 主题文件，保持与桌面端一致的配色风格。

## 非需求（Non-Goals）

- 不做动画/音效/用户可配置面板——保持纯视觉主题。
- 不替换任务栏图标、系统通知图标等二进制资源。
- 不自动检测或推送上游更新。
- 不支持浏览器端插件分发。
- 不修改 OpenCode 的任何功能行为。

## 成功指标

- 安装成功率 100%（一键命令无手动干预）。
- 补丁后 OpenCode 启动无异常、无性能可感知下降。
- 还原操作（恢复 .bak）后界面完全恢复原生。
- 用户反馈正面：界面美观、不遮挡内容、亮/暗切换流畅。
